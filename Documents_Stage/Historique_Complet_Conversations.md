Ah! Now we can see the exact data and formula used in the calculations:

### 1. Variables and Data Structure
- `AL_TARIFS_2025` is a JavaScript object storing the unit tariffs for the year 2025 for each Quotient Familial (QF) tranche (A, B, B2, C, D, E, F, F2, G).
- `AL_PRESTATIONS` is an array listing each service type (e.g., "Journée avec repas (mercredi)") along with:
  - its `cle` (mapping to the tariff object),
  - its default monthly quantity reference (`qte`) (e.g., 4 for mercredis, 16 for periscolaire, 5 for 5-day packages, 1 for stages/séjours), which corresponds exactly to the user's instructions in the requirements.

### 2. Basic Formula (Facture de base)
For a selected tranche, we compute the base cost for each prestation by multiplying its unit tariff by its quantity:
$$\text{Base Cost} = \text{Tarif Unitaire} \times \text{Quantité / Mois}$$
The total monthly base invoice is the sum of these base costs:
$$\text{Total Base} = \sum (\text{Tarif Unitaire} \times \text{Quantité})$$

### 3. Simulated Formula (Facture simulée)
When a percentage increase $P$ is selected on the slider (from 0% to 20%), the simulated unit tariff is:
$$\text{Tarif Simulé} = \text{Tarif Unitaire} \times \left(1 + \frac{P}{100}\right)$$
The total simulated monthly invoice is:
$$\text{Total Simulé} = \text{Total Base} \times \left(1 + \frac{P}{100}\right)$$

### 4. Overcost (Surcoût)
- **Monthly Overcost (Surcoût mensuel)**:
$$\text{Surcoût mensuel} = \text{Total Simulé} - \text{Total Base}$$
- **Annual Estimated Overcost (Surcoût annuel)**:
$$\text{Surcoût annuel} = \text{Surcoût mensuel} \times 12$$

### 2. Le calcul par prestation (ligne par ligne)
Pour chaque ligne du tableau, la formule est :

$$\text{Facture Base} = \text{Tarif Unitaire} \times \text{Quantité Mensuelle}$$

$$\text{Facture Simulée} = \text{Facture Base} \times \left(1 + \frac{\text{Hausse \%}}{100}\right)$$

$$\text{Surcoût} = \text{Facture Simulée} - \text{Facture Base}$$

#### Exemple avec la prestation « Journée avec repas (mercredi) » :
*   **Quantité de référence** : 4 jours par mois.
*   **Tarif de base** : 12,40 €
*   **Facture de base** : $12,40\ \text{€} \times 4 = \mathbf{49,60\ \text{€}}$
*   **Facture simulée (+10%)** : $49,60\ \text{€} \times 1,10 = \mathbf{54,56\ \text{€}}$
*   **Surcoût** : $54,56\ \text{€} - 49,60\ \text{€} = \mathbf{+4,96\ \text{€}}$

---

### 3. Le calcul des totaux globaux (les cartes en haut)

*   **Facture de base / mois** : C'est la somme de toutes les factures de base calculées pour chaque prestation.
    $$\text{Total Base} = \mathbf{478,43\ \text{€}}$$
*   **Facture simulée / mois** : C'est la somme de toutes les factures simulées.
    $$\text{Total Simulé} = \mathbf{526,27\ \text{€}}$$
*   **Surcoût mensuel** : La différence entre la facture simulée et la facture de base.
    $$\text{Surcoût Mensuel} = 526,27\ \text{€} - 478,43\ \text{€} = \mathbf{+47,84\ \text{€}}$$
*   **Surcoût annuel estimé** : On multiplie le surcoût mensuel par 12 (mois de l'année scolaire) pour obtenir l'impact sur l'année complète.
    $$\text{Surcoût Annuel} = 47,84\ \text{€} \times 12 = \mathbf{+574,12\ \text{€}}$$

Très franchement, un **audit**, c'est comme le **contrôle technique d'une voiture**, mais appliqué à une entreprise, une mairie, un service ou même un logiciel.

Dans le langage de tous les jours, ça veut dire : **"On ouvre le capot, on regarde partout pour voir si ce qu'on nous dit correspond bien à la réalité, et on cherche ce qui cloche."**

Voici les 3 étapes simples d'un audit :

1. **L'inspection (L'état des lieux)** : On prend toutes les informations (les factures, les chiffres, le code informatique) et on les épluche. On ne croit personne sur parole, on veut des preuves écrites. *Exemple dans ton projet : Tu as croisé le fichier Excel Ciril avec les données de la Mairie pour voir s'il y avait le même nombre de repas.*
2. **Le diagnostic (La traque aux erreurs)** : On cherche les "trous dans la raquette". Où est-ce qu'on perd de l'argent ? Où est-ce qu'une règle n'est pas respectée ? Où est-ce qu'il y a des doublons ou des oublis ? *Exemple : Quand tu as découvert que les enfants "Extérieurs" (EXT) n'étaient pas comptés dans le total.*
3. **Le rapport (L'ordonnance du médecin)** : À la fin, on rend un document officiel qui dit "Voici ce qui va bien, voici ce qui est complètement faux/cassé, et voici comment il faut le réparer".

**Pourquoi on fait ça ?**
- Pour être sûr qu'on ne se fait pas voler ou qu'on ne gaspille pas d'argent sans s'en rendre compte.
- Pour s'assurer qu'on respecte bien la loi (audit financier).
- Pour certifier qu'un logiciel ne va pas planter ou se faire pirater demain (audit informatique/sécurité).

En résumé : auditer, c'est **enquêter pour trouver la vérité et corriger les erreurs**. Dans ton stage, tu as fait de l'audit financier et informatique en créant un outil qui va fouiller les tableaux Excel pour ressortir les vrais chiffres sans erreur humaine.

### 2. Comment est calculé le coût unitaire par enfant ?

Le calcul du **Coût unitaire réel** par enfant s'effectue dynamiquement au niveau du backend selon la formule suivante :

$$\text{Coût unitaire réel} = \frac{\text{Dépenses Totales Réelles (du Pôle)}}{\text{Nombre d'enfants}}$$

* **Dépenses Totales Réelles :** C'est la somme de toutes les lignes de type `DEPENSE` enregistrées en base de données pour le pôle et l'année sélectionnés (ou provenant de la référence Excel 2025 en mode lecture seule).
* **Nombre d'enfants :** C'est la valeur saisie dans le champ dédié. Si la valeur saisie est vide, égale à `0`, ou non définie, le coût unitaire est automatiquement fixé à `0,00 €` afin d'éviter toute erreur de division par zéro.
* **Exemple concret (Restauration 2025) :** 
  * Dépenses réelles = $1\ 813\ 105,51$ €
  * Nombre d'enfants = $1\ 128$
  * Coût unitaire réel = $1\ 813\ 105,51 \div 1\ 128 \approx 1\ 607,36$ € par enfant et par an.
